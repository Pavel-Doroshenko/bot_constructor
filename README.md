# Конструктор ИИ-Ботов на Django REST Framework (DRF)

Платформа представляет собой backend-систему (API) для создания и управления Telegram-ботами с динамическими сценариями и интеграцией с OpenAI GPT (ChatCompletion). Система поддерживает управление состояниями пользователей (FSM) и сохранение контекста переписки в базу данных.

## 🛠 Технологический стек
* **Python** 3.10+
* **Django** 5.x (ORM, Административная панель)
* **Django REST Framework** (Архитектура API, Сериализация, ViewSets)
* **OpenAI API** (Интеграция ИИ, модель `gpt-4o-mini`)
* **pyTelegramBotAPI (telebot)** (Обработка входящих Webhook-пакетов от Telegram)

## 🚀 1. Установка и запуск проекта

### Шаг 1: Клонирование репозитория и подготовка окружения
```bash
# Клонируйте репозиторий
git clone https://github.com
cd НАЗВАНИЕ_РЕПОЗИТОРИЯ

# Создайте и активируйте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

### Шаг 2: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка переменных окружения (`.env`)
Создайте в корневой директории файл `.env` и укажите ваш секретный ключ OpenAI:
```text
OPENAI_API_KEY=sk-proj-ВашСекретныйКлючOpenAI
```

### Шаг 4: Применение миграций и создание администратора
```bash
# Создание таблиц в базе данных SQLite
python manage.py makemigrations
python manage.py migrate

# Создание суперпользователя для входа в панель управления
python manage.py createsuperuser
```

### Шаг 5: Запуск локального сервера
```bash
python manage.py runserver
```
Сервер будет доступен по адресу: `http://127.0.0`

## 🗺 2. Структура API-эндпоинтов

Все CRUD-операции возвращают стандартные статус-коды JSON (`200 OK`, `201 Created`, `400 Bad Request`).

* `GET /api/bots/` — Получить список всех ботов.
* `POST /api/bots/` — Создать нового бота.
* `GET /api/bots/{id}/` — Получить информацию о боте по его ID.
* `PUT /api/bots/{id}/` — Обновить конфигурацию бота.
* `DELETE /api/bots/{id}/` — Удалить бота из системы.
* `POST /api/scenarios/` — Создать новый сценарий диалога.
* `GET /api/scenarios/{scenario_id}/steps/` — Просмотр всех шагов конкретного сценария.
* `POST /api/steps/` — Создание нового шага с кастомной JSON-логикой для ИИ.

## 📝 3. Как пошагово создать бота через Postman

### Шаг 1: Создание сущности Бота
* **Метод**: `POST`
* **URL**: `http://127.0.0api/bots/`
* **Body** (raw -> JSON):
```json
{
  "name": "Фитнес Ассистент",
  "tg_token": "8889240024:AAFx-ВашТокенОтBotFather",
  "gpt_model": "gpt-4o-mini",
  "system_prompt": "Ты персональный тренер. Давай короткие мотивационные ответы.",
  "max_tokens_per_req": 300
}
```
*Запомните `"id"` созданного бота в ответе (например, `1`).*

### Шаг 2: Создание Сценария для Бота
* **Метод**: `POST`
* **URL**: `http://127.0.0api/scenarios/`
* **Body** (raw -> JSON):
```json
{
  "bot": 1,
  "name": "Основной опрос клиентов",
  "description": "Запускается при первом старте бота",
  "is_default": true
}
```
*Запомните `"id"` созданного сценария в ответе (например, `1`).*

### Шаг 3: Добавление Шага в Сценарий (Конфигурация логики)
* **Метод**: `POST`
* **URL**: `http://127.0.0api/steps/`
* **Body** (raw -> JSON):
```json
{
  "scenario": 1,
  "order": 1,
  "trigger_keyword": "/start",
  "payload": {
    "bot_action": "gpt_generation",
    "custom_prompt": "Ты — администратор фитнес-клуба. Вежливо поприветствуй пользователя и предложи выбрать направление тренировок: Йога или Кроссфит."
  }
}
```

## 🧪 4. Проверка и Тестирование приложения

### Вариант А: Запуск автоматических тестов (Изолированное тестирование)
В проекте реализованы unit-тесты, которые имитируют поведение серверов Telegram и мокают (подменяют) запросы к OpenAI, проверяя корректность FSM-логики без траты ваших токенов.
```bash
python manage.py test api
```

### Вариант Б: Живое тестирование в Telegram (через VS Code Туннели)
1. Убедитесь, что ваш сервер Django запущен (`runserver`).
2. В VS Code перейдите на вкладку **Ports** (Порты) в нижней панели.
3. Нажмите **Forward a Port**, введите `8000`. Нажмите правой кнопкой мыши по созданному порту -> **Port Visibility** -> измените на **Public**.
4. Скопируйте адрес из колонки *Forwarded Address* (например, `https://devtunnels.ms`).
5. Зарегистрируйте этот вебхук на серверах Telegram, отправив следующий GET-запрос через ваш обычный браузер:
   ```text
   https://api.telegram.org/bot<ВАШ_ТОКЕН_БОТА>/setWebhook?url=<ССЫЛКА_ИЗ_VS_CODE>/api/bots/1/webhook/
   ```
6. Откройте ваш созданный бот в Telegram и отправьте ему команду `/start`. В терминале VS Code отобразится лог `POST ... 200 OK`, а в базе данных (`ChatHistory`) зафиксируется контекст диалога.
